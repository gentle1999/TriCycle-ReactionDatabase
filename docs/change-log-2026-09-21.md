# 2026-09-21 变更日志

## 分子规范化与持久化

- 修复 E/Z SMILES 投影，以最终规范化分子图的序列化往返稳定性为准。
- 保留原子自由基及金属电子态附加属性，新增迁移 `0058_mol_atom_properties`。
- 调整 `0057` 回填，避免依赖后续迁移的原子属性列。
- 利用已有原子对应关系减少持久化阶段的全图匹配。
- 相同 specific/general topology 按无操作处理，不再因此拒绝数据。
- 重解析替换旧记录时清理关联反应及几何构象的无引用对象。

## TS 兼容端点与查询

- 新增默认关闭的 `TRICYCLE_TS_ENDPOINT_OPENBABEL_FALLBACK`。
- 严格结果逐端保留；缺失端使用绝对 mode ratio=1 的坐标，由 Open Babel 重建分子图；双端缺失时双端回退。
- 保存未经严格检验的状态、回退原因、方法及电子态验证证据。
- 前端增加兼容反应警告及单端、双端、任意回退和无回退记录筛选。
- 同步中英文配置与运维说明；无回退记录不等于严格验证通过。

## 导入可靠性

- MolOP 最低版本及锁定版本升级至 0.2.20，覆盖跨行 UTF-8 与代理字符回归。
- 微批持久化遇数据错误时回滚并拆分，隔离失败文件，保留其他文件及已提交前缀。
- 连接等系统性错误不递归拆批；保留取消与租约恢复机制。
- 增加 JSONB COPY、批次失败隔离、电子态往返等单元及集成回归测试。

## 提交边界

- 忽略本地 `.env`、公网 Compose 覆盖和 Caddy 配置。
- 不包含线上数据库、源文件、凭据或主机专用维护设置。

## 提交前验证

- 单元测试共 626 项：首次运行 584 项通过、42 项因本地 OIDC 配置失败；显式使用开发认证重跑涉及的全部 94 项测试后全部通过。
- Ruff 静态检查、前端类型检查与生产构建通过；构建仍提示部分资源包超过 500 kB。
- 线上 4497 个文件均为 `succeeded`，profile 刷新队列为空；成功状态包含明确标记的兼容回退，不表示所有 TS 均通过严格检验。
